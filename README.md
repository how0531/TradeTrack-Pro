TradeTrack Pro 是一款專為交易者設計的進階交易日記與績效追蹤工具。

## ✨ 核心功能

- **績效分析**：即時計算勝率、獲利因子、Max DD 等核心指標。
- **隱私保護**：一鍵模糊 (Blur) 隱藏交易金額，方便社交分享。
- **交易日曆**：直觀呈現每日損益與連勝/連敗紀錄。
- **風格分析**：自動統計各類交易策略與情緒的表現。
- **雲端同步**：支援 Firebase 即時同步，多裝置無縫接軌。

## 🚀 快速開始

### 環境需求

- [Node.js](https://nodejs.org/) (建議 v18 以上)

### 安裝步驟

1. 克隆專案：
   ```bash
   git clone https://github.com/how0531/TradeTrack-Pro.git
   cd TradeTrack-Pro
   ```
2. 安裝依賴：
   ```bash
   npm install
   ```
3. 設定環境變數：
   複製 `.env.example` 並重新命名為 `.env`，填入您的 Firebase 設定。
4. 啟動開發伺服器：
   ```bash
   npm run dev
   ```
