**修改檔案**: `src/services/brokerService.ts`

**改進內容**:

1. 添加 `AbortController` 支援請求取消
2. 設定 120 秒超時限制
3. 超時自動中斷請求
4. 友善的錯誤訊息

**關鍵代碼**:

```typescript
// 創建 AbortController 以支援取消和超時
const controller = new AbortController();
const timeoutId = setTimeout(() => {
  controller.abort();
  console.warn("⏱️ [TIMEOUT] 請求超時（120秒）");
}, 120000); // 120秒超時

const response = await fetch(`${API_BASE}/api/broker/pnl`, {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(payload),
  signal: controller.signal, // 添加取消信號
});

clearTimeout(timeoutId); // 清除超時計時器
```

**效果**:

- ✅ 避免無限等待
- ✅ 2分鐘後自動中斷
- ✅ 清楚的錯誤提示
