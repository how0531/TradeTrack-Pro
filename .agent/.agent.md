# TradeTrack Pro — 專案脈絡文件

> 專為台灣交易者打造的績效追蹤 PWA，串接永豐金證券 (Shioaji) API 自動匯入損益。

## 技術棧

| 層級 | 技術 |
|---|---|
| **前端** | React 18 + TypeScript + Vite (PWA) |
| **樣式** | Tailwind CSS 3 + Glassmorphism 自定義 CSS |
| **圖表** | Recharts |
| **圖示** | Lucide React |
| **本地資料庫** | Dexie (IndexedDB) |
| **雲端同步** | Firebase Auth + Firestore |
| **後端** | Python Flask (Shioaji API 代理) |
| **部署** | 前端: Zeabur / 後端: Render |

## 開發規範

### TypeScript

- 所有元件使用函式元件 + Hooks，不使用 Class Component
- 優先使用 `interface` 定義 props，型別定義集中在 `src/types/`
- 嚴禁 `any`，必須明確標註型別

### 樣式

- 結構佈局使用 **Tailwind CSS** utility classes
- 視覺特效 (glassmorphism, gradients, animations) 使用 **自定義 CSS**
- 維護 `tailwind.config.js` 中的 Design Tokens 一致性
- 追求高級感：毛玻璃、漸層、微動畫、暗色主題

### 金融計算

- **嚴禁浮點數直接運算**；涉及金額必須使用整數或 Decimal 處理
- 損益 (PnL) 以「點數 × 每點價值」計算，期貨口數需正確處理
- 所有日期格式統一為 `YYYY/MM/DD`（顯示）或 ISO 8601（儲存）

### 註釋

- 複雜業務邏輯、邊界條件必須寫繁體中文註釋
- 解釋「為什麼」而非「做什麼」
- 禁止無意義註釋

## 環境設定

### 本地開發

```bash
# 前端 (port 5173)
npm run dev

# 後端 (port 5000) — 需要 Python 環境
cd backend && python app.py
```

- `.env` 中 `VITE_API_URL` 為空或註解 → 自動走 `localhost:5000` (透過 Vite proxy)
- `.env` 設定 `VITE_API_URL=https://...` → 連接雲端後端

### 雲端部署

- **前端**: push 到 `main` 分支 → Zeabur 自動部署
- **後端**: push `backend/` 變更 → Render 自動部署
- ⚠️ Render 免費版會休眠，首次請求需等待約 30 秒喚醒

## 常見任務路徑

| 我想要... | 去改這些檔案 |
|---|---|
| 新增一個頁面 | `src/pages/` 新增元件 → `src/App.tsx` 加路由 → `src/components/NavBar.tsx` 加導航 |
| 修改 UI 元件外觀 | `src/components/` 對應元件 + `tailwind.config.js` |
| 調整損益計算邏輯 | `src/utils/` 計算工具 + `src/context/TradeContext.tsx` |
| 串接新的後端 API | `backend/app.py` 加 route → `src/services/brokerService.ts` 加前端呼叫 |
| 修改券商同步流程 | `src/components/modals/SyncDateModal.tsx` + `backend/core/` |
| 改商品代碼/策略清單 | `src/constants.ts` |
| 改多語系文字 | `src/locales/zh-TW.json` / `en-US.json` |

## 已知限制

1. **型別分離未完成** — `src/types.ts` 與 `src/types/` 並存，部分型別仍在舊檔案中
2. **Render 休眠** — 免費版後端閒置會休眠，導致首次 API 呼叫 timeout
3. **SyncDateModal 複雜度高** — 此元件承擔過多職責，是歷史技術債的集中點
4. **Firebase 未強制啟用** — 可離線使用 Dexie 本地儲存，Firebase 為可選雲端同步
